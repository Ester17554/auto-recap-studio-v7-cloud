# AUTO RECAP STUDIO V7 CLOUD — versão para upload pelo iPhone

Esta pasta foi achatada para facilitar o upload pelo GitHub no iPhone.
Todos os arquivos necessários ficam na raiz do repositório.

Arquivos:
- Dockerfile
- server.py
- requirements.txt
- render.yaml
- index.html
- app.js
- styles.css
- manifest.json

O servidor usa FFmpeg e fornece a interface web e a API no mesmo endereço.
